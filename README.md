# 換日線地球模型

從北極上空俯視地球的互動教學網頁，用來解釋國際換日線。

- 太陽固定在右側，地球逆時針自轉；白天明亮、夜晚加深，並畫出晨昏線
- 每 15° 一條經線；180° 國際換日線（紅）與 0° 本初子午線（白）加粗並沿線標字，午夜線與正午線為細線
- 只標示台灣、日本、英國、美東、美西五個地點與三大洋，不標大洲名稱
- 左側數字鐘：台灣、日本、英國、美東（紐約）、美西（洛杉磯），使用標準時間，不計夏令時間
- 地球下方可切換日期、調整 UTC 時間、播放；也可以直接拖曳地球旋轉
- 下方平面地圖同步顯示日夜與兩個日期的範圍

單一 `index.html`，直接用瀏覽器開啟即可。陸地輪廓取自 world-atlas（Natural Earth 1:110m）。

## 模型的簡化

- 日期分區以經度換算地方平時（每 15° 一小時），換日線畫成直的 180°
- 實際換日線會為吉里巴斯、薩摩亞等國家彎曲，本模型未畫出
